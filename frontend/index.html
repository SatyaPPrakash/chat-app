User Guide

Important: Ephemeral In-Memory Storage
Messages and sessions exist only during your active live session. Once you log out or clear your browsing session, your messages cannot be recovered. Use the "Export Chat Data" option in Settings to save a backup anytime.

Messaging & Formatting

Send text, formatted code snippets, and image/document attachments up to 5MB. Click the code icon (</>) to paste syntax-highlighted code blocks.

Message Context Actions

Right-click (or long press on mobile) on any message to reveal the action menu:

  • Reply: Quotes the target message directly above your reply.
  • Copy: Copies message text to your clipboard.
  • Pin / Delete: Manage individual messages locally.

Connection & Reliability

Socket.IO maintains a persistent WebSocket connection with automatic exponential-backoff reconnects. Live toast notifications inform you of any connection drops.
